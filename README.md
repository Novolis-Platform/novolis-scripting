# novolis-scripting

Hosted C# scripting and editor diagnostics. It is a runtime capability, distinct from source code generation.

## Packages

| Package | Purpose |
|---|---|
| `Novolis.Scripting.CSharp` | Controlled C# script execution |
| `Novolis.Scripting.Completion` | Syntax diagnostics and C# completion |
| `Novolis.Scripting.Hosting` | Combined host service |

See [getting started](docs/getting-started.md), [design](docs/design.md), and [release](docs/release.md).
